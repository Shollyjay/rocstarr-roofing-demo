# DEMO - Roofing - Landing Page Wireframe

Mobile-first wireframe for the RocStarr Media roofing niche funnel. Branded to rocstarrmedia.com.

**Summit Ridge Roofing is a fictional business.** No real company, no real people, no real data.
All reviews are labelled "Sample review". The phone number is in the reserved 555-01XX fictional range.
The RocStarr Media logo appears only in the demo banner and the footer credit, never as the
contractor's own logo - per Part 1 rule 4 of the work order.

## What to look at

- Best viewed on a phone. The layout is mobile-first.
- Fill in the form and submit to reach the thank-you page.
- The SMS consent checkbox changes the result: ticked shows the 152-character W1 text the
  customer receives; unticked shows that no SMS is sent, and why.
- Pick a booking slot to see what moves in the CRM.
- "Build notes" bottom-right overlays each section with its work-order reference.

Nothing is submitted or stored. This is a review mockup, not the built funnel.
